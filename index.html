JUEGO 7 · DESCARGA OFICIAL GRATUITA · WEB EXPERIMENTAL

Chex Quest 3

Aparece en tu Excel (registros 227, 350 y 351). El sitio oficial ofrece la aventura completa para Windows. Para el navegador, el motor Doom WebAssembly puede necesitar una variante compatible del archivo CHEX3.WAD. No está incluida ni probado el lanzamiento.

Descarga oficial ↗Probar WAD propio en Dwasm ↗

Para PC: descarga la edición oficial completa. Para nuestro navegador: coloca un CHEX3.WAD compatible en juegos/chexquest3/ y seguí las instrucciones.

🎯

Wolfenstein: Enemy Territory

Juego completo gratuito con ET: Legacy para Windows. Existe una versión WebAssembly externa que permite descargar los datos oficiales y jugar contra bots. No alojamos esos archivos en el ZIP.

Abrir en nueva pestaña ↗Descargar para PC ↗

WEB EXTERNA · PC COMPLETO DISPONIBLE · Integración local pendiente

Para PC: ET: Legacy necesita pak0.pk3, pak1.pk3 y pak2.pk3. Su instalador oficial puede obtenerlos desde la fuente autorizada. Ver VERIFICAR_ENEMY_TERRITORY.bat.
